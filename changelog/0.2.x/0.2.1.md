# 0.2.1 — 2026-10-25

## Changed

- **HTTP sessions** default to stateless when `MCP_SESSION_MODE` is unset; an explicit value still overrides the source declaration.
- **Maintenance tooling** syncs framework guidance, classifies audit advisories against the installed direct dependency, and excludes source, docs, editor settings, and caches from the desktop bundle.

## Fixed

- **Catalog text** renders Markdown punctuation, code delimiters, and entities literally after display normalization; structured API error messages stay raw until the framework renders them.
- **Image and link fields** render as Markdown images and links, including primary, large, alternate, and exhibition images. The existing response budget counts the added markup, so full artwork records can be deferred earlier.
- **Hosted-client examples** use each client's configuration shape for Claude Code, Cline, Cursor, and Claude Desktop.
