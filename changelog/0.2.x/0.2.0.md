# 0.2.0 — 2026-10-13

## Added

- **`artic_search_exhibitions`** accepts `artwork_id` and `artist_id`, combined with text and dates using AND; results cover recorded museum relationships. [#19](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/19)
- **`artic_search_artists`** returns optional numeric Getty `ulan_id` on both surfaces when recorded, distinct from the museum agent id. [#20](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/20)
- **ID continuation** attempts the first 10 artwork or 25 agent ids and returns ordered `deferred_ids`; `missing_ids` covers attempted ids only. [#18](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/18)

## Changed

- **ID input ceilings** reject more than 1,000 supplied entries, including blanks and duplicates, or comma strings exceeding 100,000 characters; normalize or split previously accepted duplicate-heavy input before calling. [#18](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/18)
- **Requested limits** accept integers through 1,000, disclose applied caps, and page using the applied size: artworks 12, artist queries and exhibitions 25, audio 2, vocabulary 100. Retain the requested limit when following `next_page`. [#21](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/21)
- **Audio pages** default to two complete stops with a maximum of two; follow `next_page` for remaining transcripts. [#13](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/13)
- **Framework tooling** syncs packaging checks and guidance; container stages use Bun 1.4.2 → 1.4.3 and prune unused musl bindings.

## Fixed

- **Artist facets** count every `artist_ids` credit and pair names by the bucket id's original source index, omitting unavailable labels. [#12](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/12)
- **Artwork histories** normalize HTML on both surfaces, preserving paragraphs and safe HTTP(S) citation destinations. [#14](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/14)
- **`htmlToText`** preserves supported entity case and table cell/row boundaries while retaining bounded processing of malformed markup. [#15](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/15)
- **Registry npm launch** uses `npx` and explicitly selects HTTP for the Streamable HTTP package entry.
