# 0.3.0 — 2026-10-28

## Added

- **`skill://art-institute-chicago-guide/SKILL.md`** resource and the `skill://{+path}` resource template: the published `art-institute-chicago-guide` Agent Skill, served via `createApp({ skills: 'skills' })`. It also ships in the npm package, the Docker image, plugin installs, and the `.mcpb` bundle. Tool schemas and annotations are unchanged.

## Changed

- **`artic_search_exhibitions`** description and the server `instructions` point to the `exhibition_history` section of `artic_get_artworks`. The exhibition relationship filters see only shows whose records list artworks, so an artwork's own history is the fuller record (for *A Sunday on La Grande Jatte*, `artwork_id` matches no exhibition while its `exhibition_history` lists shows from 1886 on).
- **`mcp-ts-core` ^0.13.16 → ^0.13.18**: fixes the HTTP transport retaining every request's signal, which grew memory under sustained HTTP traffic when the server ran on Bun, as the Docker image does (0.13.17); MCP SDK 2.4 (0.13.17); serves published skills over MCP and drops build-only framework files from the .mcpb bundle (0.13.18).
- **Packaging maintenance**: root `plugin.json` and `mcp.json` added; `.mcpbignore` lists every root dev path; `scripts/clean-mcpb.ts` selectors updated for the 0.13.18 framework layout; `bunfig.toml` `minimumReleaseAge` is 1 day; README getting-started condensed.

## Fixed

- **`artic_lookup_vocabulary`** zero-match notice no longer repeats the `contains` text. The notice is Markdown that `structuredContent` carries as-is, so the echoed text either rendered as Markdown in `content[]` or carried escape backslashes in `structuredContent`.
