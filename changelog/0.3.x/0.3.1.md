# 0.3.1 — 2026-11-03

## Added

- **`acquisition_fiscal_year`** on `artic_search_artworks` rows and `artic_get_artworks` records, with **`acquired_from`** / **`acquired_to`** filters and **`acquired_desc`** / **`acquired_asc`** sorts on `artic_search_artworks`. Works with no recorded fiscal year never match the filters and sort last; `acquired_from` above `acquired_to` fails `invalid_year_range` (#31).
- **`main_reference_number`** on `artic_search_artworks` rows (#31).
- **`facets`** on `artic_search_artworks` accepts `gallery`, `material`, `technique`, and `theme`, and all eleven names in one call (seven before) (#30).

## Changed

- **Result ceilings** rise to the API's maximums and the response byte budget is removed. Applied caps: artworks 12 → 100, artist query 25 → 100, artist ids 25 → 100, exhibitions 25 → 100, audio 2 → 100, vocabulary 100 → 1,000; defaults are unchanged (#29).
- **`artic_get_artworks`** attempts 100 ids per call (10 before, under a byte budget) and loads up to 100 related-media items (20 before). An id list whose query would pass the firewall's 2,048-byte limit goes out as consecutive GETs that each fit (#29).
- **Page window**: a saved `page` that 0.3.0 served at its smaller applied cap can now fail `page_beyond_window` when `page × limit` passes 1,000, for example `{"limit":100,"page":50}`.
- **`artic_search_exhibitions`** rows render a missing date as `closing date not recorded` or `opening date not recorded`, and `not recorded` when both are missing (#27).

## Fixed

- **Stop words** such as `the` and `of` no longer empty `artic_search_artworks`, `artic_search_exhibitions`, and `artic_search_audio_guide` results; quoted phrases and operator-bearing words are sent as typed, as is a query made only of stop words and operators (#25).
- **`artic_get_artworks`** `provenance`, `on_loan`, and `inscriptions` convert HTML to plain text instead of exposing tags (#26).
- **`htmlToText`** keeps a literal `<scheme://…>` URL as `(url)` in histories instead of deleting it as a tag (#32).
- **`artic_search_exhibitions`** `when`, `date_from`, and `date_to` no longer drop exhibitions with no recorded end date; `status` decides where the end is missing (#27).
- **`artic_search_artworks`** `date_asc` and `date_desc` keep works with no start year, sorted last, and exclude only placeholder start years (#28).
