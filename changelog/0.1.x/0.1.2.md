# 0.1.2 — 2026-10-01

## Added

- **`artic_search_artworks` `material`, `technique`, `theme`** — filters on the tagged vocabulary, case-insensitive and ANDed with the others, taking values as `artic_lookup_vocabulary` lists them (`gold leaf` matches 78 works, against 819 as query text) ([#5](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/5)).
- **Public hosted endpoint** — `https://art-institute-chicago.caseyjhand.com/mcp` (Streamable HTTP), listed in `server.json` `remotes` and the README; its callers share one `api.artic.edu` budget of 50 requests a minute.

## Changed

- **`artic_lookup_vocabulary` `filter_param`** — always present, since every vocabulary is now an `artic_search_artworks` filter; the "use as query text" line for material, technique, and theme is gone ([#5](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/5)).
- **Server `instructions`, README, and `docs/design.md`** — name the three new filters and the `POST` fallback; the README tool table and limitations are trimmed.

## Fixed

- **Search totals with quotes or numbers in `query`** — on all four search tools, `q` now carries ranking text only (quotes become word breaks, digit-led words are dropped, and a hex color sends no `q`), so `"Chicago Artists"` returns 3,412 artworks, not 2. A quoted phrase no longer lifts exact matches to the top on its own ([#4](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/4)).
- **Searches past 2,048 bytes of query string** — sent as `POST` with the same JSON body instead of failing as `request_blocked`, and cached under the GET URL; listing-by-ids routes stay GET ([#7](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/7)).
- **`artic_lookup_vocabulary` `contains` ignores accents** — `applique` finds `appliqué (technique)`, and `côte` finds `cote d'ivoire` ([#6](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/6)).
- **Title filters ignore case for accented letters** — `WIENER WERKSTÄTTE` matches `wiener werkstätte`, sent as a case-insensitive `regexp`; `place_of_origin` keeps `term` ([#8](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/8)).
- **Decomposed (NFD) Unicode** — vocabulary filter and `gallery` values ([#9](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/9)) and `query` and `artist` text ([#10](https://github.com/cyanheads/art-institute-chicago-mcp-server/issues/10)) are composed to NFC before sending, so text typed with combining accents matches its precomposed form.
