# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-01

Material, technique, and theme filters on artic_search_artworks, full search totals for quoted and numeric queries, long searches sent as POST instead of failing, and accented or decomposed text that now matches in filters, contains, and free text.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-09-30

First published release — six tools and an artwork resource over the Art Institute of Chicago public API: artwork search and full records, artists, exhibitions, audio guides, and filter vocabularies, paced under the museum's rate limit.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
